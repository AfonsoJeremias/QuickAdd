# Quick Add (Fullscreen)

**Quick Add** is an extension for [Playnite](https://playnite.link/) that lets you add games and apps to your library without ever leaving Fullscreen mode. Designed with a controller-first mindset, it eliminates the need to switch to Desktop mode or use a mouse.

## ✨ Features

- **Controller-First File Browser:** Browse your drives and folders using the D-pad or left stick. Navigate with **A** (open), **B** (back), and **Y** (places and drives). No cursor and no Windows file dialogs.
- **Multi-Add Support:** Mark multiple files with **X** (even across different folders), then press **Start** to add them all at once. You will be prompted to name each game sequentially.
- **Wide Format Support:** Add `.exe`, `.lnk`, `.bat`, and `.cmd` files. Shortcuts are automatically resolved to their target executable.
- **Move Mode (Select Button):** Need to organize your files? Mark files or folders with **X**, navigate to the destination folder, and press **Start**. The files are moved in the background with a progress bar and a completion notification.
- **On-Screen Prompts:** The current mode (Add or Move) is displayed at the top of the screen, and button prompts update dynamically.
- **Desktop Mode Support:** If you are in Desktop mode, the extension defaults to standard Windows file dialogs for convenience.

## ⚠️ Important Note
When a game folder is moved using the Move Mode, games already in your Playnite library that point to that folder are **not updated automatically**. You may need to update their paths manually if you move an installed game.

## 🚀 Installation

1. Open Playnite and go to **Add-ons** (or **Extensions**) > **Browse**.
2. Search for **Quick Add (Fullscreen)** and click **Install**.
   *(Alternatively, you can download the latest `.pext` file from the [Releases](https://github.com/AfonsoJeremias/QuickAdd/releases) page and drag it into the Playnite window).*
3. Restart Playnite when prompted.

## 🎮 How to Use

1. In Fullscreen mode, open the Playnite menu and go to **Extensions > Quick Add > Add a game or app...**
2. Use your controller to browse for the file you want to add.
3. Confirm the game's name using Playnite's virtual keyboard.
4. To move files, press **Select** to switch to Move Mode, select items, and choose a destination.
