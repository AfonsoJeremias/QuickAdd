# QuickAdd
Playnite extension to add games and apps from fullscreen mode, with a controller-friendly file browser. No need to switch to desktop mode.
# Quick Add (Fullscreen)

Playnite extension to add games/apps without leaving fullscreen mode.

Playnite menu (Back/View button) -> Extensions -> Quick Add -> "Add a game or app..."

Browse drives/folders (also Desktop, Downloads, Start menu), pick an .exe/.lnk/.bat/.cmd,
confirm the name (Playnite's on-screen keyboard), done.

## Build
Push to GitHub. Actions builds on every push; tag `v1.0.0` to get a release with the `.pext`.
